This repository is used to organize the tutorials and course project code for NUS CS5446, *Reinforcement Learning and Sequential Decision Making*.

Each tutorial and the course project will have its own folder directly under the repository root. These folders will contain the problem or project description, source code, experiment results, environment configuration, and related documentation.

Each tutorial and project will have its own folder directly under the repository root. After entering the corresponding folder, first review its solution file or project documentation, then follow the environment and usage instructions provided for that assignment.

```text
tutorial-01/
├── solution.md
├── environment.yml
└── ...

project-01/

└── ...
```

The solution file or project documentation inside each tutorial or project folder will describe:

- the problem or project objectives;
- the required environment and dependencies;
- how to run the code;
- experimental results and submission notes.

## Tutorials

### Tutorial 1 — Real World Planning and Acting

This tutorial is the first course assignment for NUS CS5446 and focuses on real-world planning and acting. It contains three problems related to Blocks World, Heuristic for Planning, and Hierarchical Task Planning.

This tutorial consists of planning analysis and written reasoning questions. It does not include code implementation, programming files, code submission, or a separate environment for running experiments.
