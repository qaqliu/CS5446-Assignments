## English

### Assignment Overview

This directory contains Tutorial 2, **Rational Decision Making**, for NUS CS5446 *Reinforcement Learning and Sequential Decision Making*. It covers the following three rational decision-making problems:

1. **Utility Matchmaker: The Case of the Mysterious Preferences**: Match four students' lottery preferences to consistent utility functions, then consider whether positive affine transformations preserve preferences.
2. **Adventures of PacBaby**: Use a logarithmic utility function to calculate PacBaby's expected utility with and without theft insurance, and calculate the insurer's expected monetary value.
3. **Allais Paradox**: Show why the common judgments in the Allais paradox conflict with normative rational analysis, then prove that they violate the substitutability axiom.

This is a Week 4 written-reasoning tutorial. It does not require code implementation, programming files, code submission, or an experimental environment. The questions and answer spaces are available in [`solution.md`](solution.md).
